# crt_functions.txt --

#     C standard library function names that should not appear as
#     undefined references in TH8 platform-neutral object files.

#     platform-specific APIs.  POSIX system calls are legitimate in
#     platform implementation files and are not flagged.
#
#     Shared by check_crt.sh (POSIX) and check_crt_msvc.bat (Win32).
#
#     Sources: ISO/IEC 9899:1999 (C99), ISO/IEC 9899:2011 (C11).
